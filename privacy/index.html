life note privacy policy

Last updated: 2026-05-04

life note respects user privacy.

Data storage

life note stores notes locally on your device.

GitHub sync

If you enable GitHub sync, your notes may be uploaded to the GitHub account or repository configured by you. GitHub sync is optional. Data sent to GitHub is handled according to GitHub’s own terms and privacy policy.

No own server

life note does not operate its own server to collect or store your notes.

Support email

If you contact support by email, your email address and message content are used only to respond to your inquiry.

Data deletion

You can delete your local data by deleting app data or uninstalling the app. If you use GitHub sync, you can also delete synced data from the GitHub repository you configured.

Data sale

life note does not sell personal data.

Contact

For privacy questions, contact jianbo.one@gmail.com.
